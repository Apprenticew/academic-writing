# LaTeX 交付约定

处理 LaTeX 稿件时，除遵循 SKILL.md 已确定的修改重点与改动幅度，还须遵守本文件的交付与保护约定。本文件不新增修改方向，也不放宽 SKILL.md 的克制原则。

## 输出形态

- 按节交付，每处给出定位：章节命令与名称，加段序或段首若干词。
- 给出可粘贴的完整段落，不用 Markdown 语法重写正文；段内不插入解释性批注。
- 单轮结束给出改动清单，逐条包含定位、原句、改后句、依据的选定功能。作者只要改动本身时可以省略清单，但每处改动仍须可定位。
- 作者要求 diff 或修订标记时，使用稿件既有工具或所处平台的输出，不自行发明新命令。
- 只做诊断时同样遵守上述定位方式，不使用“第三段第二句”这类脱离稿件坐标的指代。

## 必须原样保留的内容

| 类别 | 例子 | 约定 |
|---|---|---|
| 引用与交叉引用 | `\cite{}`、`\ref{}`、`\eqref{}`、`\label{}` | 原样保留，不重排、不合并、不改 key、不改引用顺序 |
| 自定义命令 | `\newcommand` 定义的宏、`\ours{}`、`\method{}` 之类 | 沿用稿件既有写法，不替换为字面展开，不新增宏 |
| 数学 | `$...$`、`equation`、`align`、`\mathbb{}` 等 | 不改符号与公式；涉及符号命名时先说明再询问 |
| 排版命令 | `~`、`\%`、`\ `、`\,`、`\vspace`、`\small` | 不擅自增删；确需改动时单独列出并说明理由 |
| 浮动体 | `figure`、`table` 及其位置参数 | 语言类修改一律不动 |
| 结构命令 | `\item`、`enumerate`、`itemize`、贡献条目 | 保持既有形式，不因语言修改在列表与段落之间转换 |
| 元信息 | `\author`、`\affiliation`、`\usepackage`、匿名化设置 | 不动 |
| 注释 | `%` 注释行 | 保留，除非作者明确要求清理 |

## 术语、符号与跨位置统一

- 沿用稿件已定义的术语与符号，不引入同义替换或与既有宏冲突的新写法。
- 改动某处术语时，先确认它在正文、图注、表注和附录中的用法，再决定是否统一；只统一确有歧义的位置。
- 缩写首次出现的位置及其后的使用方式按稿件既有约定处理，不擅自移动定义点。
- 语言层的修改不改变章节标签与 `\label` 命名，也不为排版方便重排章节顺序。

## 常见破坏及其避免

| 破坏 | 后果 | 避免方式 |
|---|---|---|
| 把 `\cite{a,b}` 拆成两句各带一个引用 | 编号顺序与作者意图改变 | 保持引用簇边界 |
| 为通顺删去 `\emph{}`、`\textbf{}` 一类强调命令 | 强调功能丢失 | 保留命令，或换成自然表达后确认重点仍在 |
| 把带 `~` 的短空格改为普通空格 | 行末出现孤立标号或单位 | 原样保留 `~` |
| 为补承接在段落间新增整段 | 触发页数变化与浮动体位置变化 | 优先在段内补足，见 SKILL.md 篇幅一节 |
| 把 `\item` 贡献条目改为连贯段落 | 与作者已认可的形式冲突 | 需要改变形式时先说明再询问 |
| 按 Markdown 习惯转义或替换标点 | 编译错误，或与稿件标点惯例不一致 | 输出前按本稿惯例核对 |

## 交付前的检查

- 每一处改动能用稿件坐标定位，作者不需要搜索就能找到。
- 没有误改引用、宏、公式、排版命令或浮动体安排。
- 修改都归属到已选功能；未选方向的问题只标注、不执行。
- 若有篇幅约束，压缩是否按 SKILL.md 的顺序进行，被删位置是否属于“不因省字删除”一列。
