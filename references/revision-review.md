# 多轮修订

用于多轮修改中反复出现的问题、作者要求重读先前反馈，以及检查全文意见是否完整落实。重点是找出阅读问题为何仍然存在，单次简单润色无需执行整套流程。

## 先确认要求是否被准确理解

回看与问题相关的原始反馈、已确认稿件和当前修改，不要只依赖前一轮编辑者的摘要。

区分作者明确要求、示例、尚未采纳的建议和后续修正。较新的局部要求只更新其适用位置，不能自动取消其他范围内仍有效的要求。例如，某处导航被判为重复，不代表所有章节导航都应删除。

抓住反馈想改善的阅读体验及其适用范围。例如，“平淡”可能是在要求强化思想与价值，“突兀”可能是在要求补足研究推进；不要只围绕被点名的词句改写。

## 重复反馈意味着需要重新诊断

反馈再次出现时，检查上次修改是否只改变表面形式。按实际问题选择层级，不将所有反馈都升级为全文重构：

| 读者感到的问题 | 需要重新检查什么 | 修订后的判断依据 |
|---|---|---|
| 内容都有，却看不出发现和价值 | 核心认识、问题的重要性、概念提炼及各节的推进 | 读者能说出这项工作发现了什么、为什么值得关注 |
| 生硬、割裂、没有重点 | 句间关系、指代、主从安排、语气与新信息位置 | 读者能在当前位置理解关系，并辨认应记住的判断 |
| 已换过词但仍不专业 | 具体对象、动作、领域搭配和概念性结论是否清楚 | 表达自然地承担该段任务，而非仅替换为较长词汇 |
| 小节开头仍然突兀 | 上文留下的问题是否能引出本节目的 | 读者在看到操作前知道为何需要这一步 |
| 调整顺序后仍难理解 | 概念、操作、指标和论证前提是否真正建立 | 当前推理可由此前给出的信息理解，而非只改变编号 |
| 假设与实验仍不呼应 | 前文问题、实验目的、结果认识与全文主线的联系 | 结果后明确回答相应问题；出现假设名称本身不算完成 |
| 只修好了少数例句 | 同类问题在授权范围内还有哪些位置 | 相关位置均经判断，未机械插词或全局替换 |

## 从相邻文本检验阅读是否顺畅

读修改段落及其前后衔接，仅使用读者到当前位置掌握的信息。逐句检查这句话为何出现、指向什么对象、怎样承接前句，以及主要判断落在哪里。

尤其检查段首目的是否从已有科学问题自然引出。若读者还不知道为什么值得检验某种性质，直接以“为了测量这种性质，我们……”开头仍然突兀。补足真实的研究理由，不用已经选定的测量操作反向制造动机。

已有逻辑只缺标记时，可以采用最小修订；缺少研究桥梁、概念前提或段落职责时，应修正这些问题。增加连接词数量、扩大段落篇幅或交换小节位置都不是独立的完成标准。

## 检查覆盖范围和既有安排

- 全文同类问题反馈意味着检查所有相关位置，包括后半篇、讨论、图表注与适用的附录；只授权局部修改时保持局部范围。
- 保留原表达承担的功能。替换某个总结短语仍需保留总结；突出贡献不自动新增列表；压缩篇幅不先删必要条件与承接。
- 不同位置分别判断。引言概述、正文导航、假设回扣各有职责，针对一处的修改不能机械推广。
- 对照修改前后，检查是否意外改变已确认的段落形式、图表位置、浮动方式或引用。语言任务确需涉及这些安排时，说明实际必要性。
- 检查相邻重复和总篇幅，优先将新增解释融入原段，避免每次修订都叠加一层说明。

## 根据实际稿件收束

逐项检查关键要求是否在成稿中可见，不用泛泛的“已加强逻辑”代替实际修改。有效的原文可以保留，修改量本身不是质量指标。
